# Factory Card Game Web Prototype v0.1

企画書 v0.2 を正本にした、アップデート前提の Web プロトタイプです。

## 起動
ES Modules を使っているため、フォルダを HTTP サーバーで配信してください。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。GitHub Pages / Netlify Drop にもそのまま配置できます。

## 現在入っているもの
- 工業画面 / 戦闘画面の即時切替
- 建築資材、自動増加、施設データ駆動
- 施設配置、回転、連続配置、解体
- 4原料 / 8単純加工 / 5合成加工
- 自動生産（作れるレシピのうち内部コスト最安）と手動カードレシピ
- コンベア経路、既存経路からの分岐・合流、交差を接続しない設計の基礎
- 倉庫の在庫 / 通常・仕分け・サーチ用データ構造
- 2x2出荷エリアと境界編集、手札容量の区画配分
- 素材を含む全アイテムの手札カード化
- 5列x2段戦闘、初回リロード、相打ち向け同時攻撃処理、10秒撤去、自壊
- 支援バフの重複、タグメタの基礎
- 練習用AI
- 工業画面上部の簡易戦況表示
- 2.5D風の戦場UI（本格3Dレンダラへ差し替え可能）

## まだ「完成」扱いではないもの
- 本格オンライン対戦
- Babylon.js / Three.js 等による本格3Dモデル戦闘
- 全補助カードの特殊ターゲットUI
- 強化インラインモジュールのUI
- 倉庫の複数出口ごとの独立設定UI
- 偵察カード
- 最後の一撃スローモーション
- 数値バランス全般

これらはコアロジックと表示を分離しているため、後続フェーズで追加する前提です。
