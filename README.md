# FACTORY CARD GAME — Phase 1 工場基盤

**これは試験用の初期骨格であり、CPU対戦の完成版ではありません。**

## 起動・公開
- 開発時: VS Code Live Server または `python -m http.server 8000` で起動（ES Modules のため file:// 直開きは非推奨）。
- GitHub Pages: リポジトリのルートを公開する設定にすれば動作します。外部依存はありません。
- 操作: 建築物選択→盤面クリックで配置、Rで回転、撤去ボタン→クリックで撤去、ベルトボタン→始点・終点クリックで直線敷設。

## 実装済み
32×32盤面（暫定値）、2×2資源ゾーン4か所、採集施設4種類、施設の重なり禁止、建築資材の自然増加、建設・撤去、直線ベルトの基本描画・設置、描画とルールモジュールの分離。

## 未実装（次のフェーズ）
ベルトへの実アイテム搬送、分流・合流、採集の生成、内部在庫、製造工程、強化、倉庫、出荷、手札、戦闘、CPU、オンライン、再接続・セーブ。

## 注意
現段階では採集施設を置いても資源は生成されません。交差等の複雑なベルト接続は表示だけの初期試験で、仕様v0.3の物流処理は未実装です。オンライン版はGitHub Pagesのみでは動きません。
